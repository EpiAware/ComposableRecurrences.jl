About these benchmarks ​

Against hand-written code ​

The aim is to be as fast as hand-written code with hand-written adjoints. Each tutorial's model is timed against a hand-written loop of the same model, differentiated by the same backend. The table gives the loop's minimum time over the package's, so above 1 the package is faster and below 1 it is slower.

Reverse-mode gradients gain most, because the package's own adjoints replace differentiating the loop. The forward run and ForwardDiff use no adjoints, so they are near the loop's speed and slower than it on several models. The package is slower than the loop in these cases:

julia
slower_cases()

  • Forward run: backend delay (0.70×), vaccination (0.77×), occupancy (0.66×), latent processes (0.93×).

  • ForwardDiff: renewal (0.76×), vaccination (0.95×), reproduction number (0.98×), occupancy (0.85×), latent processes (0.95×), time-varying delays (0.86×).

  • Mooncake: never slower.

  • Enzyme: imports (0.93×), latent processes (0.83×).

Issue #417 tracks the slower cases and issue #506 forward-mode adjoints.

The performance summary gives each example its own table, with the package's times and the gain from its rules. Each row names its case in test/ADFixtures/src/matrix_cases.jl, timed at the docs tier, and task -t benchmark/Taskfile.yml matrix-docs regenerates benchmark/results/docs.csv, which these tables read. The AD comparison times the gradient of every scenario in the AD test registry on each backend.

The suite ​

ComposableRecurrences benchmarks its core operations to track performance over time.

The "AD gradients" group times the gradient of each scenario in the package's AD test registry on each backend the package targets: ForwardDiff, and Enzyme and Mooncake in forward and reverse mode. The AD tests also run ReverseDiff, but the suite does not time it. Scenarios declared broken or skipped for a backend are left out of that backend's rows. The "Evaluation" group times the forward run of each benchmark matrix case at its CI size. Each matrix case also has gradient rows on the reverse-mode backends, once as users call the operator and once, prefixed "NoAdjoint", with any hand-written adjoint bypassed.

Each entry takes one evaluation per sample for up to a second, so a single history point is indicative rather than exact.

Run the suite locally with julia --project=benchmark benchmark/run.jl.
