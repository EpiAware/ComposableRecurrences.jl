ComposableRecurrences.each! Function
julia
each!(
    body,
    _::ComposableRecurrences.Serial,
    n,
    work,
    args...
)
julia
each!(body, ex::Executor, n, work, args...)

Call body(k, args...) for every k in 1:n with executor ex:

where each index k is one stratum (see PerStratum), one series or one output time.

body must write only the slots it owns for index k, so the indices can run in any order or at the same time. A new executor type adds a method of each!. Returns nothing.

Arguments

  • body: the per-index function, called as body(k, args...).

  • ex: the executor that runs the loop.

  • n: the number of indices.

  • work: an estimate of the loop's total cost in inner operations, which an executor may use to run small loops in order; Serial ignores it.

  • args: the arguments passed to every call of body.

Examples

julia
using ComposableRecurrences
const CR = ComposableRecurrences
# Row sums of a matrix, one row per index.
rowsum!(k, y, A) = (y[k] = sum(view(A, k, :)); nothing)
A = [1.0 2.0; 3.0 4.0]
y = zeros(2)
CR.each!(rowsum!, CR.Serial(), 2, length(A), y, A)
y

# output

2-element Vector{Float64}:
 3.0
 7.0

ComposableRecurrences.forward Function

Run operator op over a whole call, returning (y, cache).

This is the ComposableRecurrences.Run role: calling the operator lowers to forward(op, Run(), args...; kwargs...). For inputs it computes

with the operator's own maths, and cache holds what the reverse pass needs. Couplings, modifiers and depletion forms write their outputs in place through ComposableRecurrences.forward! instead.

Arguments

  • op: the operator.

  • role: Run().

  • args: the call's arguments.

Examples

julia
using ComposableRecurrences
CR = ComposableRecurrences
y, cache = CR.forward(Convolution([0.5, 0.5]), CR.Run(), [1.0, 2.0, 3.0])
y

# output

3-element Vector{Float64}:
 0.5
 1.5
 2.5

ComposableRecurrences.test_adjoint Function

Test the analytic adjoint of piece in role on the primal arguments args with the AD backend's own rule tester.

The tester checks the pullback against finite differences of the forward map  : for random directions and cotangents ,

with from finite differences and from the pullback.

For an operator, role is ComposableRecurrences.Run and args are its positional arguments. Methods come from package extensions: AutoMooncake with Mooncake loaded (Mooncake.TestUtils.test_rule) and AutoEnzyme with EnzymeTestUtils loaded (test_reverse, with the operator active and constant).

Arguments

  • backend: an AutoMooncake or AutoEnzyme from ADTypes.

  • piece: the operator.

  • role: Run().

  • args: the positional arguments.

Examples

julia
using ComposableRecurrences
methods(ComposableRecurrences.test_adjoint)
