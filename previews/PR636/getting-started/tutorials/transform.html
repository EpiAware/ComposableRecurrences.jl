Branching processes ​

Introduction ​

A branching process follows the offspring of each case, and its expectations, such as the mean cases by type or the probability of extinction, are recurrences. The operators compute these expectations; they do not simulate chains.

Packages used ​

K = [1.2 0.4; 0.3 0.6]
by_generation = Recurrence([1.0]; coupling = K)(1.0; history = [1.0; 0.0;;], stop = 30)
growth = norm(by_generation[:, end]) / norm(by_generation[:, end - 1])
radius = maximum(abs, eigvals(K))

    @subset(:cases .> 0)

    draw(_; axis = (xlabel = "Generation", ylabel = "Mean cases (log scale)", yscale = log10))
end

After a few generations both types grow at the same rate, in a fixed ratio. By generation 30 the growth per generation is 1.3583, the spectral radius of to four decimal places. The ratio of type 1 to type 2 cases is then 2.53.

Isolation thins the later lags most. It brings the reproduction number from 1.6 to 0.886, below one. The mean offspring with and without isolation match seeded branching-process simulations from EpiBranch.jl; the isolation use case checks them.

Isolation delay by type ​

The delay to isolation can depend on a case's state. Once a household's first case is found, later cases in it are found sooner. In expectation each infector type gets its own thinned kernel, a PerStratum kernel. Type 1 is a household's first case and type 2 a later case. The next-generation matrix scales each column of the coupling by its type's kernel sum. Its spectral radius is the reproduction number:

Here is the mean number of type cases on day and   the gain. The coupling is the mean offspring matrix, K_house in the code. The weight is type 's thinned kernel on lag , row of W_house. The next-generation matrix is ngm_house.

julia
F_fast = [0.3, 0.7, 0.9, 1.0, 1.0]
W_house = permutedims([gi_isolated gi .* (1 .- p * b .* F_fast)])
K_house = [0.6 0.3; 0.6 0.5]
house_model = Recurrence(PerStratum(W_house); coupling = K_house)
house = house_model(R0; history = [10.0; 0.0;;], stop = 60)
ngm_house = R0 * K_house * Diagonal(vec(sum(W_house; dims = 2)))
R_house = maximum(abs, eigvals(ngm_house))

@chain DataFrame(
    "day" => 1:60, "First case" => house[1, :], "Later case" => house[2, :]
) begin
    stack(Not(:day); variable_name = :type, value_name = :cases)
    data(_) * mapping(:day, :cases, color = :type) * visual(Lines, linewidth = 2)
    draw(_; axis = (xlabel = "Day", ylabel = "Mean cases (log scale)", yscale = log10))
end

The reproduction number, the spectral radius of , is 0.773. From 10 seed cases the mean number of cases of both types falls towards zero, to 0.014 in total on day 60.

Contact tracing as two types ​

Traced and untraced cases are two types. A share of each case's contacts is traced, and traced cases use the thinned kernel. A Pairwise kernel gives each pair of types its interval. Rows are the infectee type and columns the infector type:

where type 1 is untraced and type 2 traced. The kernel is the Pairwise weight on lag from infector type to infectee type . The full kernel is gi and the thinned one is gi_isolated. The gain is  . This is an approximation: tracing correlates an infector's and infectee's isolation times.

julia
function traced_outbreak(ψ)
    A_trace = zeros(2, 2, length(gi))
    for (col, g) in enumerate([gi, gi_isolated])
        A_trace[1, col, :] = (1 - ψ) .* g
        A_trace[2, col, :] = ψ .* g
    end
    return Recurrence(Pairwise(A_trace))(R0; history = [10.0; 0.0;;], stop = 60)
end
@chain [0.0, 0.5, 0.9] begin
    map(ψ -> DataFrame(day = 1:60, ψ = string(ψ), cases = vec(sum(traced_outbreak(ψ); dims = 1))), _)
    reduce(vcat, _)
    data(_) * mapping(:day, :cases, color = :ψ => "Traced share") * visual(Lines, linewidth = 2)
    draw(_; axis = (xlabel = "Day", ylabel = "Cases (log scale)", yscale = log10))
end

More tracing means fewer cases. On day 60 there are 90 252 cases with no tracing, 590 with half traced and 2.3 with 90% traced. With 90% traced the outbreak declines.

The Transform is also given the partial derivatives of in and in as derivative. With    , they are

A gradient's reverse pass uses these. Without them it would evaluate on dual numbers at every step, which costs more than the closed form.

julia
G(s, θ) = (1 + θ.R / θ.κ * (1 - s))^(-θ.κ)
function dG(s, θ)
    u = 1 + θ.R / θ.κ * (1 - s)
    y = u^(-θ.κ)
    return θ.R * y / u, (; R = -(1 - s) * y / u, κ = y * (θ.R * (1 - s) / (θ.κ * u) - log(u)))
end
function extinction(θ, n)
    m = Transform(G, θ; derivative = dG)
    return Recurrence([1.0]; modifiers = (m,))(; history = [0.0], stop = n)
end

generations = 30
@chain [0.1, 0.5, 1.0, 10.0] begin
    map(_) do κ
        q = extinction((; R = 1.5, κ), generations)
        DataFrame(generation = 1:generations, κ = "κ = $κ", q = q)
    end
    reduce(vcat, _)
    data(_) * mapping(:generation, :q, color = :κ) * visual(Lines, linewidth = 2)
    draw(_; axis = (xlabel = "Generation", ylabel = "Probability of extinction"))
end
