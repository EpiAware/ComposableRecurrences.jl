Parameters and gradients ​

A modifier parameter can take any form and still get its gradient, building on Writing new types.

julia
using ComposableRecurrences
const CR = ComposableRecurrences
ComposableRecurrences

The gradient mirror ​

grads.piece mirrors the type's fields, one entry per field, by field type:

FieldMirror entry
float scalarRef, add with x̄[] += g
float arrayan array of the same shape
PerStratum, TimeVarying or another structa NamedTuple of its own fields' mirrors, such as (; x = zeros(S))
integer, range, nothing, functionnothing
struct with no fields(;)

The whole mirror, or any entry, is nothing when the backend holds it constant. Read an entry with cotangent, which returns nothing for such a field, and add to it with add_cotangent!, which skips nothing. For a modifier parameter, use param and add_param! instead, which accept every parameter form, including Derived and Recent. Call add_param! for every parameter, even with a nothing mirror, as a Recent parameter still sends its cotangent to the outputs it read.

A per-stratum parameter ​

This modifier adds to the value of stratum :

It reads b with param and adds its cotangent with add_param!, so b may be one value or PerStratum. For a PerStratum b the mirror entry is (; x), and the cotangent of entry k lands in x[k].

julia
struct Shift{B}
    b::B
end
CR.blocks(::Shift) = (1, 1)
function CR.forward!(m::Shift, ::CR.Step, v, s, t)
    for k in eachindex(v)
        v[k] += CR.param(m.b, k, t)
    end
    return nothing
end
function CR.pullback!(grads, m::Shift, ::CR.Step, v, s, t)
    b̄ = CR.cotangent(grads.piece, :b)
    for k in eachindex(v)
        CR.add_param!(b̄, m.b, grads.v[k], k, t)
    end
    return nothing
end

m = Shift(PerStratum([0.1, 0.2]))
grads = (; piece = (; b = (; x = zeros(2))), v = [1.5, 0.5], s = [0.0, 0.0])
CR.pullback!(grads, m, CR.Step(), [2.0, 1.0], [0.0, 0.0], 1)
grads.piece.b.x
2-element Vector{Float64}:
 1.5
 0.5

A pointwise modifier reads each parameter at its own stratum, param(m.b, k, t), and its Init at time 1, param(m.b, k, 1). A call checks the PerStratum parameters of a pointwise or blockwise modifier against the number of strata.

Local rules for maps ​

The map of a Derived parameter or a Transform is differentiated one entry at a time. Without a rule of its own, each entry takes a local forward-mode derivative, which evaluates the map on dual numbers. A map whose derivative has a closed form can say so with a pullback! method in the Local role. It receives the map's value at the entry, as the forward pass computed it, before the map's arguments, and returns the partial derivatives, one per argument.

Write the map as a callable struct, or a named function, so the method is for a type you own. A reporting-delay hazard on the logit scale,   , has    :

julia
struct LogisticSum end
(::LogisticSum)(a, γ) = inv(1 + exp(-(a + γ)))
function CR.pullback!(grads, ::LogisticSum, ::CR.Local, y, a, γ)
    d = y * (1 - y)
    return d, d
end

hazard = CR.Derived(LogisticSum(), [-2.0, -1.5, -1.0], TimeVarying(zeros(6)))
delay = TimeVarying(CR.Increments(1 - CR.Survival(hazard)), CR.Primary())
round.(CR.kernel_weights(delay, 2); digits = 3)
3×2 Matrix{Float64}:
 0.119  0.119
 0.161  0.161
 0.194  0.194

The operators find the method from the types, so a map without one costs nothing to check. A Transform map f(v, θ) returns (∂f/∂v, ∂f/∂θ), the second shaped as θ. A map with float fields of its own keeps taking plain AD, as the rule gives no gradient for those fields; pass them in θ.
