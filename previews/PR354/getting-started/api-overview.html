API overview ​

Getting started builds a model of three towns one part at a time. The model has two operators: the renewal, a Recurrence, and the reporting delay, a Convolution. Each operator is built from a kernel, the weights it puts on past values, and runs when it is called. A coupling and modifiers change how a recurrence steps.

Some public names are not exported, so using ComposableRecurrences does not bring them in. They are written without the package prefix on this page. Load them with using ComposableRecurrences: Depletion, Floor, State, and so on. The neural network package Lux also exports a Recurrence, so with both loaded write ComposableRecurrences.Recurrence.

A step ​

A model can run several series side by side, such as one per town. Each of these series is a stratum, and together they are the strata.

Each day, a recurrence takes a weighted sum of each stratum's recent outputs. The coupling then mixes these sums between strata. The gain, such as the reproduction number, scales the result. The values given as add are then added. Each modifier then changes the value in turn. A modifier can keep a state from day to day, such as the people left to infect. A convolution takes a weighted sum of an input series, from the current day back, scales it by the gain and adds add. It has no coupling and no modifiers.

Operators ​

Recurrence and Convolution are the two operators. Each is built once from a kernel and then called like a function. A recurrence computes each value from its own past values, such as infections from earlier infections. A convolution weights the past values of another series, such as reported cases from earlier infections.

julia
renewal = Recurrence(gi)
delay = Convolution([0.0, 0.1, 0.25, 0.3, 0.2, 0.1, 0.05])
NameWhat it doesReturns
Recurrence(kernel; lags, step, coupling, modifiers)computes each value from its own last values; kernel[1] weights lag 1a Recurrence to call
Convolution(kernel; lags, step, method)computes each value from the current and past inputs; kernel[1] weights lag 0a Convolution to call

lags and step apply when the kernel is a delay distribution. The keyword method sets how a convolution sums its lags. The method Direct() sums them one by one. The method FFTMethod() uses a fast Fourier transform. The method Auto(), the default, takes the transform for a kernel of at least 300 lags over at least 1000 days.

Calls ​

A call runs an operator over a range of days. A recurrence takes its gain first, and a convolution takes its input first and its gain as a keyword. In the table, renewal is a Recurrence and delay a Convolution, as in Getting started.

julia
infections = renewal(R; history = seed)
reports = delay(infections; gain = 0.4)

A State holds what a run needs to continue: the last outputs, each modifier's state, and state.t, the day the next step computes.

Every input that changes over time is indexed by day, counted from day 1 of the gain, whatever start is. So the gain on day is always gain[t]. stop defaults to the common length of those inputs. Inputs of different lengths without a stop are an error. Without a gain, a recurrence takes a gain of 1. A trace holds one matrix per modifier in trace.modifiers, with a column per day. Without modifiers or add, the outputs divided by their pressure, y ./ pressure(renewal, y; history), are the gain each day, the reproduction number. With a Depletion they are the effective reproduction number.

Shapes ​

A slot is a place an operator reads numbers from: a kernel, a coupling or a modifier parameter. A plain array gives one set of numbers for every stratum and day. A wrapper gives one set per stratum, per pair of strata or per day. In Getting started, PerStratum(pop) gives each town its own population.

julia
Depletion(PerStratum(pop))

A route is one way infection passes between strata, such as contact in the community or at funerals. Each route has its own kernel and its own coupling.

NameWhat it means
vectorone kernel, the weights on each lag, shared by every stratum
PerStratum(x)one kernel or parameter for each stratum, with the strata as the first index
Pairwise(A)one kernel for each pair of strata, indexed by receiving stratum, giving stratum and lag
Routes((K₁, k₁), (K₂, k₂))a sum of routes, each a coupling and a kernel
TimeVarying(x)a kernel, coupling or parameter that changes by day, with the days as the last index
TimeVarying(P, Primary())a time-varying kernel whose column belongs to input day
Derived(f, args...)a parameter computed by f from other parameters
Recent(n)a parameter that sums the recurrence's own last n outputs, for each stratum and day

A Pairwise or Routes kernel mixes the strata itself, so the coupling is left as the identity matrix, LinearAlgebra.I. A TimeVarying kernel can be given as a vector with one kernel per day, each of any length. It can also be given as change points: start => value pairs, each value holding from its start day. By default, column of a time-varying kernel belongs to output day , Secondary(). It holds the weights the output on day puts on earlier days, such as the delays of the reports on day . With Primary(), column belongs to input day . It holds how the value on day spreads over later days, such as the delays of the infections on day . For a recurrence, the value on day is its own output. The parameter Derived(exp, TimeVarying(x)) is the exponential of a parameter that changes by day. The parameter Recent(7) sums the last seven outputs, and β * Recent(7) is that sum times a number β. The parameter Recent(7; coupling = K) mixes the recent outputs between strata. Wrappers combine: TimeVarying(PerStratum(G)) is a strata × lags × days kernel. Most wrappers hold the stored array without copying it. A bare vector where a single value is expected is an error that names the wrapper to use. Inputs and outputs are strata × days arrays, histories are strata × days before the run, and none of them is wrapped.

Delay distributions ​

A delay distribution, such as a gamma generation interval, can stand in for a kernel. The operator turns it into masses: the probability that the delay falls on each whole lag.

julia
Recurrence(Gamma(2.0, 2.5); lags = 15)

Gamma comes from the Distributions.jl package, and a continuous delay such as it needs CensoredDistributions.jl loaded. A type works as a delay when it has a delay_masses method, which gives its masses on lags 0 to lags - 1. With Distributions.jl loaded, discrete distributions have masses. With CensoredDistributions.jl loaded, continuous distributions have them too. A convolution's kernel starts at lag 0, so it keeps the delay's mass on lag 0. A recurrence's kernel starts at lag 1, so it drops that mass. So Convolution(d; lags = 4) has 4 kernel entries and Recurrence(d; lags = 4) has 3. The keyword step is the width of one lag in the delay's unit, 1 by default. A model with a weekly time unit and delays in days takes step = 7.

KernelHolds
done delay
(d₁, d₂)a chain of delays, one after another
PerStratum(ds)a vector of delays, one per stratum
Pairwise(D)a matrix of delays, with D[i, j] the delay of stratum j in stratum i
TimeVarying(ds, indexing)a vector of delays, one per day
Routes((K₁, d₁), (K₂, d₂))delays or arrays as route kernels

The argument indexing is Secondary() or Primary(), as for any time-varying kernel. TimeVarying also takes PerStratum or Pairwise of delays, with time last. Pairwise and Routes kernels work with Recurrence only. A chain may also hold mass vectors, and it is itself a delay, so it fits wherever d does.

Couplings ​

A coupling says how much each town's infections drive the others'. In Getting started, K is a gravity coupling.

julia
Recurrence(gi; coupling = K)

Row of a coupling is the stratum that receives, and column the stratum that gives. The coupling acts on the weighted sums of past outputs, before the gain.

NameWhat it does
LinearAlgebra.I, the identity matrixno mixing
λ * LinearAlgebra.I, the identity times a number λevery sum scaled by λ
strata × strata matrixmixing such as contact or travel
TimeVarying(K), with K strata × strata × daysmixing that changes by day
a type you writea new coupling

The matrix can be dense, Diagonal or sparse.

Modifiers ​

A modifier changes each day's value after the gain. In Getting started, Depletion(PerStratum(pop)) draws each town's infections from the people left to infect.

julia
Recurrence(gi; coupling = K, modifiers = (Depletion(PerStratum(pop)),))

Modifiers act in tuple order, and each keeps its own state. The add input enters before every modifier, and an Add enters where it sits in the tuple. A Convolution has no modifiers.

A Depletion holds pools, such as the people left to infect. Each pool has a name and a starting size, given as pools, such as (S = N, V = 0.0). The value a step asks for is drawn from the pools.

NameWhat it doesParameters
Depletion(N, parts...; pools)draws each day's value from a poolN, each starting pool and each part's parameters
Depletion(cap, Truncate(; into = :O); pools = (:O,))fills pool :O up to a capacity capthe capacity
Flow(from => to, rate; form)a part that moves values from pool from to pool to each daythe rate
Redistribute(M; leak)moves a share of each stratum's value to other strataM
Add(b)adds at this point in the orderb
Clamp(lo, hi)bounds each valuelo, hi
Allocate(groups, total)rescales each group of strata to a known totaltotal
Transform(f, θ)maps each value through θ

The parts of a Depletion are draws and flows, and they act in the order given. A draw is a depletion form, and Depletion(N) alone draws with Hazard(). A Flow names pools by their names in pools, and 0 stands for outside the model. A draw takes each pool's share of the draw as a keyword of its form, such as Hazard(; weights = (S = 1, V = σ)). A small pool cannot give all a step asks for. A draw's overflow keyword sends what it leaves to a second stratum (:stratum), to a queue that joins the next day's demand (:queue), or nowhere (the default). A Depletion with flows and no draw only moves values between pools, as for patients moving between wards. A Redistribute moves whatever it receives, including values from add. Its matrix M has columns that sum to one, so the total is kept. With leak = true a column can sum to less than one, for a share lost on the way. The function movement(K, ε) builds M from a kernel K and an intensity ε, moving a share ε[q] * K[p, q] of stratum q's value to stratum p. An Allocate keeps each stratum's share of its group. With imports = (fraction, pattern), a fraction of each total is shared out by a second pattern instead. Every parameter is a number, PerStratum(x), TimeVarying(x), TimeVarying(PerStratum(x)), a Recent or a Derived of these. A pointwise modifier acts on each stratum on its own. Add, Clamp and Transform are pointwise. So is a Depletion with one pool whose draws leave nothing over. Redistribute and Allocate act on several strata. Each modifier here has its own hand-written gradient. A Transform has one when it is given a derivative, or when f holds no numbers of its own.

Depletion forms ​

A depletion form sets how a pool gives up what a step asks for. Each form is a type, passed as an instance.

julia
Depletion(N, Floor())
NameWhat it doesExample
Hazard(α)draws the value as a hazard, so the pool never goes negative; the defaultDepletion(N)
Floor(α)scales the value by the share of the pool left, with a floorDepletion(N, Floor())
Truncate()draws what is asked for, up to what is leftDepletion(Truncate(); pools = (S = B,)) for a budget B
SoftTruncate(κ)a smooth Truncate(), with softness κ between 0 and 1Depletion(cap, SoftTruncate(0.1; into = :S))
Share()a flow that moves a share of its pool each dayFlow(:S => :V, p; form = Share()) moves a share p of :S to :V
a type you writea new depletion formDepletion(N, MyForm())

The heterogeneity exponent α of Hazard(α) and Floor(α) is one by default; above one, infections slow sooner as the pool shrinks, as when the most susceptible are infected first. A flow's form is Hazard() by default: a rate that competes with the pool's other flows. With Truncate() or SoftTruncate(κ) a flow is a count, capped by what remains. A new depletion form is a type with a forward! method for one step, Step().

Time-series processes ​

A latent process is one that is not observed, such as a random walk on the log reproduction number. It is also a recurrence or a convolution, driven by noise . A recurrence takes the noise as add, and a convolution as its input.

julia
Recurrence([1.0])(; history = [0.0], add = ϵ)
ProcessMathsCode
Random walk  Recurrence([1.0])(; history = [z0], add = ϵ)
Autoregression, AR(p)  Recurrence(φ)(; history, add = ϵ)
Autoregression with a coefficient that changes by day  Recurrence(TimeVarying(reshape(φ, 1, :)))(; history, add = ϵ)
Moving average, MA(q)  Convolution(vcat(1, θ))(ϵ)
Weighted sum of a recurrence's past outputs Convolution(vcat(0, k))(y; history)

These calls have no gain, and the run is as long as ϵ. reshape(φ, 1, :) makes a kernel of one lag with a column per day. The last row recomputes from a recurrence's output y, as operators return only their outputs.

Executors ​

An executor sets where an operator's loops run: in order, on threads or on a device such as a GPU. The default runs in order.

julia
with(EXECUTOR => Threaded()) do
    renewal(R; history = seed)
end
NameWhat it doesReturns
EXECUTORthe executor every call inside a with block usesa setting
Serial()runs the loops in order; the defaultan executor
Threaded()runs the loops on threadsan executor
Device(backend)runs the loops on a device, such as a GPU's KernelAbstractions.jl backendan executor

with comes from Base.ScopedValues, and the setting holds inside its block only.

Extension API ​

These names are for writing a new coupling, modifier or depletion form, and for checking its gradient. A model built from the package's own parts needs none of them. A new type does its work in a forward! method for each role it has. A role is one job, chosen by a type with no fields. The role Step() computes one step, and Init() the starting state. The role Pressure() is a coupling's mixing, and Trace() a modifier's record for a call with trace = true. The role Run() is an operator's whole call. An operator's hand-written gradient is its rule.

ispointwise(m)whether a modifier acts on each stratum on its ownBool

param(x, k, t)reads a parameter for stratum k on day ta value
add_param!(x̄, x, v, k, t)adds to a parameter's cotangentnothing
cotangent(x̄, name)the cotangent of a fielda cotangent, or nothing
add_cotangent!(x̄, v, idx...)adds to a cotangentnothing

For an operator, pass Run() as the role to uses_adjoint, PieceInterface and test_adjoint. blocks gives (nv, ns), the number of values and of state entries in each group. It is (1, 1) for a pointwise modifier and nothing for one that reads every stratum. ispointwise and nstate are read from blocks. A run keeps at least depth past outputs, even when the kernel is shorter.

Checking gradients ​

A rule can be checked against the gradient that automatic differentiation computes from the operator's code.

NameWhat it doesReturns
NoAdjoint(op)the same operator, differentiated by automatic differentiation instead of its rulean operator
ComposableRecurrences.test_adjoint(backend, op, ComposableRecurrences.Run(), args...)runs the rule tester of an automatic differentiation package on an operator's rulea test result

The gradient through NoAdjoint(op) checks the gradient through op, and timing both compares their cost. backend names the automatic differentiation package, such as Mooncake or Enzyme. test_adjoint needs the Mooncake package, or the Enzyme and EnzymeTestUtils packages, loaded.
