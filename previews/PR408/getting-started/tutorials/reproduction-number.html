The reproduction number from a run ​

Introduction ​

A renewal multiplies the sum each day draws against by its reproduction number. The function pressure recomputes that sum from a run's output:

where is the infections of stratum on day , the generation interval on lag and the coupling. The ratio   recovers the reproduction number. Without modifiers it is the gain , the instantaneous reproduction number. With depletion it is the effective reproduction number. It builds on the Getting started example.

Packages used ​

using ComposableRecurrences

The instantaneous reproduction number ​

The one-town renewal of Getting started, with its intervention from day 50:

is the number of infections on day and the generation interval on lag , with   lags. is the reproduction number, the gain . It is 1.8 up to day 50 and falls in equal steps to 0.8 on day 56. The run starts from ten infections on each of the six days before day 1. Passing the run's history to pressure gives the first days the seed terms they need.

julia
gi = [0.05, 0.2, 0.3, 0.25, 0.12, 0.08]
T = 75
R = [1.8 - clamp((t - 50) / 6, 0, 1) for t in 1:T]
seed = fill(10.0, 6)
renewal = Recurrence(gi)
infections = renewal(R; history = seed)
R_hat = infections ./ pressure(renewal, infections; history = seed)

@chain DataFrame(day = 1:T, value = R, series = "Gain") begin
    data(_) * mapping(:day, :value => "Reproduction number", color = :series => "") *
        visual(Lines, linewidth = 2)
    _ + data(DataFrame(day = 1:T, value = R_hat, series = "Infections / pressure")) *
        mapping(:day, :value => "Reproduction number", color = :series => "") *
        visual(Scatter, markersize = 6)
    draw(_; axis = (xlabel = "Day",))
end

The ratio recovers the gain to round-off on every day. Where the pressure is zero, as in a stratum no infection has reached, the ratio is NaN with no infections and Inf otherwise. With strata the pressure includes the coupling, for any kernel and coupling a Recurrence takes.

The effective reproduction number ​

A pool of susceptibles, after day , depleted by the hazard form, draws

  is the pressure and the hazard on day .   is the town's population, and the pool starts there,  . The gain   is the one above, and the Depletion is the only modifier. A call with trace = true also returns each modifier's Trace. For a Depletion its first row is the pool after each day, which gives .

julia
N = 60_000.0
depleted = Recurrence(gi; modifiers = (Depletion(N),))
y, tr = depleted(R; history = seed, trace = true)
q = pressure(depleted, y; history = seed)
R_eff = y ./ q
pool = [N; only(tr.modifiers)[1, 1:(end - 1)]]
λ = R .* q ./ N
@assert R_eff ≈ R .* pool ./ N .* -expm1.(-λ) ./ λ

@chain DataFrame(day = 1:T, Gain = R, Effective = R_eff) begin
    stack(Not(:day); variable_name = :series, value_name = :R)
    data(_) * mapping(:day, :R => "Reproduction number", color = :series => "") *
        visual(Lines, linewidth = 2)
    draw(_; axis = (xlabel = "Day",))
end

The effective reproduction number matches the hazard formula above to round-off. It falls below the gain as the pool runs down. It falls below 1 on day 38, two days after infections peak and before the intervention on day 50. After day 75 the pool holds 28% of the town.

Imports added after the depletion by Add are not multiplied by the gain. With them,   is the effective reproduction number. An add input enters before the depletion and is drawn with the rest, so the ratio then includes its share.
