using ComposableRecurrences
using ComposableRecurrences: Depletion, Clamp, Add

Order ​

The modifiers of a Recurrence act on each step's value in tuple order, after the gain and add. With modifiers , each with its own state , a step computes

where is the value after the gain and add, the value modifier passes on, and the output. Each sees the value the one before it passed on, so the order is part of the model. A pool is a quantity a modifier carries from step to step and draws from, such as the people left to infect. A cap applied before depletion draws the capped value from the pool, and a cap applied after it only limits what is reported. With the cap   and the hazard form of a pool of , the two orders give

julia
k = [0.3, 0.4, 0.3]
gain = fill(2.5, 15)
seed = [1.0, 2.0, 3.0]
pool(N) = Depletion(N; pools = (S = N - sum(seed),))
cap_first = Recurrence(k; modifiers = (Clamp(0.0, 8.0), pool(100.0)))
cap_last = Recurrence(k; modifiers = (pool(100.0), Clamp(0.0, 8.0)))
round.(cap_first(gain; history = seed)[end-2:end]; digits = 2),
round.(cap_last(gain; history = seed)[end-2:end]; digits = 2)
([2.85, 2.55, 2.17], [0.94, 0.59, 0.37])

Imported cases have the same choice: through add they are drawn from the pool, and through an Add after a Depletion they do not deplete it.

State ​

Each modifier keeps its own state from step to step, such as the remaining pool of a Depletion. The state starts from the call's history through the modifier's Init, or at zero. It is carried in the State a call returns, so a resumed call carries on with it.

julia
r = Recurrence(k; modifiers = (pool(100.0),))
y, state = r(gain; history = seed, state = true)
state.states
([10.466045960048065],)

A modifier's state is one entry per stratum unless its blocks gives another count, which nstate reads. A modifier that needs no state leaves it at zero.

Scope ​

A modifier's step reads one stratum, one group of strata or every stratum. The trait blocks is (1, 1) for the first, the values and state entries of each group for the second, and nothing for the third. A pointwise modifier reads and writes each stratum on its own. The scope sets how much the step can do, and how well it runs under Threaded: strata run apart only when every modifier is pointwise.

A modifier acts on a Recurrence only; a Convolution has none. Its parameters take every form in Slots.

Choosing a modifier ​

Several needs have more than one fit.

  • To bound values, Clamp cuts them and a Depletion filled up to a capacity routes, queues or drops what is cut, so it keeps account of the excess.

  • To move values between strata, Redistribute moves them after the gain through a movement matrix whose columns sum to one, a Depletion without a draw moves between the pools of a group, and a coupling mixes before the gain.

  • To map values, Transform takes any function, and write a new modifier when the map keeps state or reads other strata.

A new modifier composes with the built-ins in the same tuple.
