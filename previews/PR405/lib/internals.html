ComposableRecurrences.Auto Type
julia
struct Auto <: ComposableRecurrences.ConvolutionMethod

The default method of a Convolution. A call with a fixed kernel (a vector or PerStratum) of lags, outputs and Float64 arrays on the CPU, once the weak dependency of the FFT extension is loaded, takes

Any other call takes ComposableRecurrences.Direct. From these sizes the transform is faster than the direct method on typical series, forward and in reverse mode: by 1.02 to 1.14 times at 300 lags and 1000 outputs, and 1.5 to 2.1 times at 500 lags and 2000 outputs. Below them the direct method is faster, up to 2 times. So most models take the direct method, and Float32 models never take the transform. The kernel, eltype, arrays and loaded packages are resolved by dispatch, and the sizes by two integer comparisons per call.

Its accuracy, and its cost on a series spanning many orders of magnitude, are those of ComposableRecurrences.FFTMethod.

Examples

julia
using ComposableRecurrences
k, x = [0.5, 0.5], [1.0, 2.0, 4.0]
Convolution(k)(x) == Convolution(k; method = ComposableRecurrences.Direct())(x)

# output

true

ComposableRecurrences.Run Type
julia
struct Run

The role of an operator's whole call, forward(op, Run(), args...; kwargs...), which returns (y, cache); calling the operator lowers to it.

For inputs (the call's arguments and the operator's fields) it computes the output over the call's times  ,

with the maths of the operator, a Recurrence or a Convolution; cache holds what the reverse pass needs, such as the ComposableRecurrences.State. It is the role an operator is asked about, as in uses_adjoint(op, Run()), PieceInterface with role = Run() and test_adjoint(backend, op, Run(), args...).

ComposableRecurrences.Trace Type
julia
struct Trace

The role of a modifier's trace: what a call with trace = true records for it at each step.

At absolute time the modifier maps its values and state to , and its trace is

with the modifier's own map: by default its state after the step,  , and a modifier whose state never changes, such as ComposableRecurrences.Add, records nothing. A ComposableRecurrences.Depletion with a draw records its pools after the step, the value it passes on and the overflow   , what its draws leave of the demand and the queue (zero without one), with rows for each pool, then the values passed on, then the overflows, each over the strata or groups; without a draw it records the amount each flow moves, a row per flow over the groups. ComposableRecurrences.Redistribute records its arrivals, its state. A modifier records its trace with forward!(m, Trace(), r, v, s, v′, s′, t), writing into r, which takes the shape of v for its kind of step: for a pointwise modifier (ComposableRecurrences.ispointwise) a tuple of vectors, one per trace value, indexed by stratum as v is, their kth entries filling row (j - 1) * S + k; for a blockwise modifier (ComposableRecurrences.blocks), as forward!(m, Trace(), r, v, s, v′, s′, t, g) for group g, a tuple of one-entry views filling rows (j - 1) * G + g for groups, with v, s, v′ and s′ tuples of one-entry views; for any other modifier the step's column of ComposableRecurrences.ntrace rows. Its pullback, pullback!(grads, m, Trace(), v, s, t) (with g for a group), is given grads = (; piece, trace, v, s, v′, s′): trace holds the cotangent of r, in its shape, and the pullback adds the cotangents of the step's inputs and outputs into v, s, v′ and s′ and those of the modifier's parameters into piece.

Examples

julia
using ComposableRecurrences
CR = ComposableRecurrences
r = ([0.0], [0.0], [0.0])
CR.forward!(CR.Depletion(100.0), CR.Trace(), r, [2.0], [80.0], [1.6], [78.4], 1)
r

# output

([78.4], [1.6], [0.3999999999999999])

contributions(c::Convolution, x; kwargs...) -> Any

The lag contributions of a Convolution: the terms of its sum over lags, before the sum,

in the notation of Convolution, so that   . A ComposableRecurrences.Primary kernel reads  , so is the part of the input at time   that arrives at : a reporting triangle by arrival time. Terms whose input is before the history, or past a ragged column's end, are zero.

ComposableRecurrences.depth Function
julia
depth(x) -> Int64

The number of past outputs x reads from a recurrence's buffer, before the current step.

A Recurrence keeps

past outputs per stratum, where is the kernel length, is depth and are the modifiers. The kernel reads the last of them; the deeper rows are kept for objects that read further back than the kernel. A ComposableRecurrences.State holds the last outputs, so a resumed call reads the same past. The default recurses by value through the fields of immutable structs, tuples and named tuples and takes the largest. Numbers, arrays, functions, mutable objects and operators (which keep their own buffers) read nothing,  , so an object held inside an array or a mutable struct is not counted. Add a method for a type that reads the buffer.

Arguments

  • x: any object, such as a modifier, coupling or kernel.

Examples

julia
using ComposableRecurrences
CR = ComposableRecurrences
struct Window
    w::Int
end
CR.depth(x::Window) = x.w
CR.depth((Window(5), (; a = Window(9), b = 1.0))), CR.depth(CR.Clamp(0.0, 1.0))

# output

(9, 0)

ComposableRecurrences.each! Function
julia
each!(
    body,
    _::ComposableRecurrences.Serial,
    n,
    work,
    args...
)
julia
each!(body, ex::Executor, n, work, args...)

Call body(k, args...) for every k in 1:n with executor ex:

where each index k is one stratum or one output time.

body must write only the slots it owns for index k, so the indices can run in any order or at the same time. A new executor type adds a method of each!. Returns nothing.

Arguments

  • body: the per-index function, called as body(k, args...).

  • ex: the executor that runs the loop.

  • n: the number of indices.

  • work: an estimate of the loop's total cost in inner operations, which an executor may use to run small loops in order; Serial ignores it.

  • args: the arguments passed to every call of body.

Examples

julia
using ComposableRecurrences
const CR = ComposableRecurrences
# Row sums of a matrix, one row per index.
rowsum!(k, y, A) = (y[k] = sum(view(A, k, :)); nothing)
A = [1.0 2.0; 3.0 4.0]
y = zeros(2)
CR.each!(rowsum!, CR.Serial(), 2, length(A), y, A)
y

# output

2-element Vector{Float64}:
 3.0
 7.0

Base.transpose Method

transpose(
    c::Convolution
) -> ComposableRecurrences._TransposedConvolution
julia
transpose(c::Convolution)
c'

The transpose of the convolution c: a sum that reads the series forward from each time rather than back from it,

for a ComposableRecurrences.Primary or fixed kernel, in the notation of Convolution: if c without a gain or add input computes  , the transpose computes  . A ComposableRecurrences.Secondary kernel (the default for a TimeVarying kernel) weights by  , the column of the time it reads. c' is the same operator, and the transpose of the transpose is c.

Called as transpose(c)(x; tail = nothing, start = 1, stop), it covers the absolute times start:stop:

  • x: the series, length n or S × n, read at absolute time t.

  • tail: the series after t = n, oldest first (any length m, or S × m); later values are zero. A series extended by its last value is tail = fill(x[end], L - 1).

  • start: the first time; 1 by default.

  • stop: the last time, at most n + m; n by default.

The output has the layout of x and length stop - start + 1. A Primary() kernel covers times up to stop, and any other TimeVarying kernel the last time it reads, min(stop + L - 1, n + m).

It takes the direct method whatever the method of c.

Examples

julia
using ComposableRecurrences
c = Convolution([0.5, 0.25, 0.25])
c'([1.0, 2.0, 4.0, 8.0])

 2.0

ComposableRecurrences.uses_adjoint Function
julia
uses_adjoint(piece, role) -> Bool

Whether piece carries its own analytic adjoint in role: a ComposableRecurrences.pullback! method for that role.

For outputs   of the role, with inputs and parameters , the adjoint computes the cotangents

by hand, where is the gradient of a scalar loss with respect to .

By default it is true when pullback! has a method for the type of piece and role whose other arguments are untyped, so writing the method is enough. The lookup is read from the types, so the route costs nothing per call. A method with a typed grads or typed arguments is not found, apart from a blockwise group step's with v::Tuple, s::Tuple; declare uses_adjoint(::T, role) = true for any other, which ComposableRecurrences.PieceInterface checks. A method of uses_adjoint also overrides the default, for example when the adjoint covers only some values of a type. If it is true but no pullback! method fits the arguments, the reverse pass throws a MethodError. An operator uses its adjoint in ComposableRecurrences.Run when it has one. A Recurrence does when every float it holds is a Float16, Float32 or Float64 and each part has a pullback! or a local step within its limits.

Arguments

  • piece: the operator, coupling, modifier or variant.

  • role: the role.

Examples

julia
using ComposableRecurrences
CR = ComposableRecurrences
CR.uses_adjoint(Recurrence([0.5, 0.5]), CR.Run())

# output

true
