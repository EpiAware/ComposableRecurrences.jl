Occupancy and capacity ​

Introduction ​

Bed occupancy is the admissions weighted by the chance of still being in a bed, a convolution over the length of stay. This tutorial models occupancy, bed capacity and the movement of patients within a ward.

What are we going to do in this exercise ​

  1. Turn admissions into occupancy with a convolution and with a recurrence.

  2. Compare a log-normal stay with the same mean.

  3. Cap occupancy at the number of beds with Clamp.

  4. Admit up to the free beds with a Depletion and keep the rest.

  5. Move suspected and confirmed patients between two compartments.

What might I need to know before starting ​

The Getting started overview; no fitting is involved.

Occupancy two ways ​

For any length-of-stay distribution, occupancy is the admissions weighted by the probability of still being in a bed:

Because the geometric distribution is memoryless, only this stay collapses the sum to a recurrence of order one:

The admissions enter the recurrence as add.

julia
T = 90
admissions = [30 * exp(-((t - 35) / 12)^2) for t in 1:T]
δ = 0.15
by_convolution = Convolution((1 - δ) .^ (0:(T - 1)))(admissions)
by_recurrence = Recurrence([1 - δ])(; history = [0.0], add = admissions)

@chain DataFrame(
    "day" => 1:T, "Admissions" => admissions,
    "Occupancy (convolution)" => by_convolution,
    "Occupancy (recurrence)" => by_recurrence
) begin
    stack(Not(:day); variable_name = :series, value_name = :count)
    data(_) * mapping(:day, :count, color = :series) * visual(Lines, linewidth = 2)
    draw(_; axis = (xlabel = "Day", ylabel = "Patients"))
end

Occupancy peaks a few days after admissions at nearly six times their height, because each patient stays about days.

julia
maximum(abs, by_convolution .- by_recurrence)
5.684341886080802e-14

A stay that is not geometric ​

Real stays are rarely geometric: the chance of leaving changes with the time already spent in bed, and a few patients stay much longer. A log-normal stay with log-mean and log-standard deviation , discretised by day, has

where is the probability of a stay of whole days and the log-normal distribution function. The survival is 1 .- cumsum(pmf), lag 0 first. Here  , and is chosen so that the mean days in bed, , match the geometric stay's .

julia
σ = 1.2
function survival(μ)
    F(x) = x <= 0 ? 0.0 : erfc(-(log(x) - μ) / (σ * sqrt(2))) / 2
    pmf = [F(k + 1) - F(k) for k in 0:(T - 1)]
    return 1 .- cumsum(pmf)
end
function matched_mu(target; lo = 0.0, hi = 3.0)
    for _ in 1:50  # bisect on μ until the mean days in bed match
        mid = (lo + hi) / 2
        sum(survival(mid)) < target ? (lo = mid) : (hi = mid)
    end
    return lo
end
S = survival(matched_mu(1 / δ))
by_lognormal = Convolution(S)(admissions)
round.((sum(S), 1 / δ); digits = 2)
(6.67, 6.67)
julia
@chain DataFrame(
    "day" => 1:T, "Admissions" => admissions,
    "Geometric stay" => by_convolution, "Log-normal stay" => by_lognormal
) begin
    stack(Not(:day); variable_name = :series, value_name = :count)
    data(_) * mapping(:day, :count, color = :series) * visual(Lines, linewidth = 2)
    draw(_; axis = (xlabel = "Day", ylabel = "Patients"))
end

The log-normal stay gives a lower, later peak and a longer tail. For the same mean, more patients leave within two days and more stay beyond two weeks than with the geometric stay. The rest of this tutorial uses the geometric stay, as a pool's share exit flow and the hazard flows do.

A bed cap ​

Clamp bounds each day's occupancy. With beds,

The cap applies before occupancy carries over to the next day, so patients turned away never occupy a bed later.

julia
beds = 120.0
capped = Recurrence([1 - δ]; modifiers = (Clamp(0.0, beds),))(; history = [0.0], add = admissions)

@chain DataFrame(day = 1:T, Uncapped = by_recurrence, Capped = capped) begin
    stack(Not(:day); variable_name = :series, value_name = :count)
    data(_) * mapping(:day, :count, color = :series) * visual(Lines, linewidth = 2) +
        mapping([beds]) * visual(HLines, color = :grey, linestyle = :dash)
    draw(_; axis = (xlabel = "Day", ylabel = "Occupied beds"))
end

Capped occupancy holds at 120 beds for about ten days, then falls before the uncapped one. The bed-days lost to the cap are

julia
round(sum(by_recurrence .- capped))
670.0

Admitted and turned away ​

The cap deletes the patients it turns away. A Depletion that fills a pool keeps them instead. It admits each day's demand up to the free beds and routes the rest to a second series:

where is the number of free beds and the admissions. The second series receives the   patients turned away. Its one pool :O is the occupancy, and its state. The draw form = Truncate() with fill = :O fills it with the admissions, up to beds. A share flow Flow(:O => 0, δ; form = Share()) empties it first, as flows_first = true. overflow = :stratum sends what is turned away to the second series. Series 1 holds the demand, and the zero kernel passes it straight to the modifier.

julia
routing = Depletion(
    beds; pools = (:O,), form = Truncate(), fill = :O, flows_first = true,
    flows = Flow(:O => 0, δ; form = Share()), overflow = :stratum
)
routed = Recurrence([0.0]; modifiers = (routing,))(;
    history = zeros(2, 1), add = [admissions'; zeros(1, T)]
)
admitted_occupancy = Recurrence([1 - δ])(; history = [0.0], add = routed[1, :])

turned = DataFrame("day" => 1:T, "Admitted" => routed[1, :], "Turned away" => routed[2, :])
@chain turned begin
    stack(Not(:day); variable_name = :series, value_name = :count)
    data(_) * mapping(:day, :count, color = :series) * visual(Lines, linewidth = 2)
    draw(_; axis = (xlabel = "Day", ylabel = "Patients"))
end

Admissions fall to the beds freed each day while the ward is full. The occupancy of those admitted never passes the number of beds, and no patient is lost:

julia
maximum(admitted_occupancy), sum(routed) ≈ sum(admissions)
(120.0, true)

An allowance granted each period works the same way, with a pool drawn from rather than filled. Vaccine doses per week are one example: a flow Flow(0 => :B, grants; form = Truncate()) brings each week's doses into the pool :B. The Depletion docstring gives it and the other models of pools and flows.

A ward with two linked compartments ​

A ward holds suspected patients awaiting a test and confirmed patients. Each day some suspected patients are confirmed and move to the confirmed compartment. Others are ruled out and leave, and confirmed patients are discharged. Confirmation and ruling out compete for the same suspected patients. Let be the suspected compartment, the confirmed compartment and the admissions. With confirmation rate , rule-out rate and discharge rate ,

The rates are hazards, so the share leaving a compartment never exceeds what it holds. The two compartments are the strata of a recurrence with the unit kernel, suspected first. The recurrence carries yesterday's compartments forward and adds the admissions to the suspected one. A Depletion without a draw then applies the day's flows. Its pools are the compartments, held in the strata. Each flow is a Flow from one pool to another, or to 0 to leave, with a hazard rate as its demand. Each rate is a parameter, so it can differ by ward or change over time. Here  ,   and  .

julia
ward_flows = Depletion(;
    pools = (:suspected, :confirmed), form = nothing,
    flows = (
        Flow(:suspected => :confirmed, 0.3), Flow(:suspected => 0, 0.4),
        Flow(:confirmed => 0, 0.1),
    )
)
ward = Recurrence([1.0]; modifiers = (ward_flows,))
patients = ward(; history = zeros(2, 1), add = [admissions'; zero(admissions')], stop = T)

@chain DataFrame(day = 1:T, Suspected = patients[1, :], Confirmed = patients[2, :]) begin
    stack(Not(:day); variable_name = :series, value_name = :count)
    data(_) * mapping(:day, :count, color = :series) * visual(Lines, linewidth = 2)
    draw(_; axis = (xlabel = "Day", ylabel = "Patients"))
end

Suspected patients peak first. Confirmed patients peak about a week later and stay longer, as they leave more slowly.

A flow with form = Share() moves a share, like the daily discharge probability above, except that the day's admissions can also leave that day. A flow with form = Truncate() moves a count capped by what the compartment holds, such as a fixed number of transfers a day. With wards the strata are the suspected compartments, then the confirmed ones.
